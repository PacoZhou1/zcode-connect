# 执行过程的图标、排版、状态与过渡规范

版本 127 · 2026-09-14。适用于手机端会话中的工具行、执行过程汇总与展开详情。SF Symbols 为 Apple 原生矢量资源，不打包位图图标库，不额外下载图标字体。

## 设计规则

这是针对用户截图的产品设计判断，不是用户研究结论。平台来源：[Apple SF Symbols](https://developer.apple.com/sf-symbols/) 与 [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/sf-symbols)。

1. 图标始终表示操作类别；状态用文字表达。不能让所有完成操作都变成对勾、所有运行操作都变成空圈。
2. 每个图标配可见动作标签。未知工具保留真实名称，不伪装成已支持的专用能力；未知状态显示“状态未确认”。
3. 工具行按原始顺序显示，不把命令重新排到文件操作之前，不改变执行因果关系。
4. 单项直接显示，多项提供汇总展开入口；完成后的总过程摘要展开时直接显示工具行，避免重复套层；完整输入和输出保留在详情，不把大量 JSON、代码、补丁堆进会话正文。
5. 工具过程属于内容层，用普通原生 Button / DisclosureGroup，不给每一行铺 Liquid Glass 卡片。

## 排版与交互

- 图标列宽 22pt，字形约 17pt、regular，图文间隔 8pt；正文使用系统 subheadline。
- 思考、摘要与工具明细统一至少 28pt（按用户参考图收紧，大字号自然增高），纯工具消息之间不叠加段落留白；行内摘要正常字号为一行，中间省略。无障碍大字号允许最多三行，状态可换行，行高随内容增长。
- 图标不随摘要长短改变横向位置，状态不被长命令挤掉，DisclosureGroup 使用统一紧凑样式，箭头与展开状态同步。
- 默认单色 secondary；失败状态文字用红色并明确写出失败，中断明确写“已中断”，不只用颜色区分。
- 图标对 VoiceOver 隐藏，操作、对象、展开状态由文字/原生控件提供；整行是可点击区域。长按不是展开所必需的手势。
- 每一行独立展开；组可整体展开。用户已打开的详情不会在工具完成时自动被收走。

## 状态与动效

- running：正在运行/读取/修改，网页使用“获取中”“搜索中”，不显示工具行尾部转圈，状态由文字表达。
- waiting/pendingApproval：等待确认；queued：排队中。等待批准不伪装成正在运行。
- success/completed：已运行/已读取/已获取等。
- error/failed/rejected：动作失败。cancelled/interrupted：已中断。
- 缺失或未知状态：状态未确认，不自动解释为成功。
- 只展示后端真实提供的耗时；目前无逐工具可靠计时，故不制造“耗时”或随页面开启计时。已有消息级总用时单独标注。
- 工具组全部成功且后续文字出现时，0.28 秒 easeInOut 收成摘要；最终正文确认时，前面的过程区域平滑收起、结果淡入。
- 用户正在查看详情、回看上文、存在失败或待确认步骤时，保留过程展开。历史会话首次打开不回放完成动效。
- 开启“减弱动态效果”时禁用自动过渡动画；保留明确状态和可展开入口。

## 触感

- 电脑 accepted 回执：轻触 impact。排队/引导沿用同一确认路径，超时不能误报成功。
- 回答完成：UINotificationFeedbackGenerator.success。由数据层确认，不依赖当前 SwiftUI 视图是否收到了 running 状态变化。
- 支持完成事件先于正文、正文先于完成事件、混合新旧历史、第一条快速回答、排队后下一轮已运行等次序。
- 按配置范围、任务和回复/轮次去重；载入已结束的历史不震动。遵循触感设置。前台触感不能替代后台系统通知。

## 性能与数据

网站图标同源请求，无第三方 favicon 服务；缺失时始终有 SF Symbol 回退。新增行内摘要只保存白名单字段，最多四项，字符串最多 512 字符、数组最多三个短元素，不再次复制整个补丁或正文，也不增加远程全文读取请求。

## 验证

19 种符号在目标 iOS 模拟器用 UIImage(systemName:) 检验存在性。状态/摘要/边界使用生产模型测试；视觉、点击和动效用专用模拟器验收。实际真机震感必须由真机体验确认，不能由模拟器宣称完成。证据保存于 docs/backend/evidence/tool-experience-125。

本轮验收：61/61 状态测试、161 断言，10/10 Relay 适配测试，19 个 SF Symbols 在目标系统均能创建。专用模拟器 Computer Use 已验点按详情、组收起/展开、完成后摘要恢复、主动查看的详情不自动收起、深色与无障碍大字号。真机触感手感未由模拟器证明。
